# Weekly audits

One file per week, `YYYY-MM-DD.md`, dated the last day the audit covers. They're written by the
`mnemosyne-weekly` skill (`.claude/skills/mnemosyne-weekly/SKILL.md`). Each one records the week, findings with their
evidence, the changes Aman approved (file and commit), and the number each change should move. The next audit
starts by checking those numbers, then keeps, revises, or reverts each change.

Not to be confused with `docs/audit-*.md`, which are snapshots of the collection's state (`scripts/audit.py`).
